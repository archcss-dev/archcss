## Features

- Utility-first: Compose any design directly in your HTML
- Lightweight & fast: Minimal footprint, instant load
- Highly customizable: Tailor to your project’s needs
- Modern responsive design out of the box
- Easy integration with any frontend stack

---

## Quick Start

Get Architect CSS in your project:

- **CDN:**
  ```html
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/archcss@2.0.1/arch.min.css">
  ```
- **npm:**
  ```bash
  npm install archcss@2.0.1
  ```
- **Download:** [Latest release (.zip)](https://github.com/archcss-dev/archcss/archive/v2.0.1.zip)
- **Clone:**
  ```bash
  git clone https://github.com/archcss-dev/archcss.git
  ```

[Previous releases](https://github.com/archcss-dev/archcss/releases) are also available.

## Usage Example

```html
<button class="bg-blue-600 text-white px-4 py-2 rounded hover:bg-blue-700">
  Click me
</button>
```
